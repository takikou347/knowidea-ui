動き

状態が変わるときだけ動かす。タグの色は 160ms、ボタンの hover は 120ms、どちらも cubic-bezier(0.2, 0, 0, 1)。読み込み中の回転は読み込みの間だけ。prefers-reduced-motion では遷移も回転も止める。

選んだ理由

この会社の画面は、routine、PR、待ちの件数を毎朝一度に見る道具なので、余白より表の読みやすさを取り、時刻と PR 番号を等幅にして縦に通した。

色の温度を灰で止めたのは、状態の緑、黄、赤を迷わず読ませるため。主の青は主のボタンと今いる所だけで、成功の緑と並んでも混ざらない。

名前を持たない既定の見た目にならないよう、Plex の日本語と等幅を同じ家族でそろえ、影は浮くメニューだけ、区切りは枠 1 本にした。
