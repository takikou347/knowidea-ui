# KNOW IDEA のロゴと主の色

見本は `index.html`。SVG は `logo/`。

## コンセプト

| 項目 | 中身 |
| --- | --- |
| 形 | 「03. ループ」。太い 1 本のなめらかな波の線(端は丸い)と、右上に離れた丸い点 1 つ |
| 意味 | 流れ、循環、試行錯誤、発見 |
| 隠れた要素 | K は流れる線、I は点 |
| 添える一言 | 答えはまだ無い。だから試す。 |

## 色

| 名前 | 値 | 使う所 |
| --- | --- | --- |
| 主(ライト) | `#016C6C`(OKLCH はおよそ 0.48 0.08 195) | マーク、主のボタン、今いる所 |
| 主(ダーク) | `#4CBFBF` | ダークの面のマークと主のボタン |
| ダークの面 | `#1F2328` | ダークのアプリのアイコン、ダークの背景 |
| 単色の濃 | `#4B6B6B` | 単色の印刷、控えめな所 |
| 単色の薄 | `#C7CED3` | 透かし、無効 |

均一の平らな色だけ。グラデーション、影、ぼかしは使わない。

| --- | --- | --- | --- |
| ライト | 白 | `#016C6C` | `mark.svg` |

| 単色の濃 | 白 | `#4B6B6B` | `mark-mono-dark.svg` |
| 単色の薄 | 白 | `#C7CED3` | `mark-mono-light.svg` |
| アプリ(ライト) | 面 `#016C6C` | 白 | `app-icon-light.svg` |
| アプリ(ダーク) | 面 `#1F2328` | 白 | `app-icon-dark.svg` |

## 大きさ

| 大きさ | 使う所 | ファイル |
| --- | --- | --- |
| 128px | アプリ、大きな見出し | `mark.svg` |
| 64px | メニュー | `mark.svg` |
| 32px | リスト | `mark.svg` |
| 16px | 最小。これより小さくしない | `mark-16.svg`(線と点を太くした形) |

24px までは `mark-16.svg` を使う。上のバーの 24px も同じ。

## まわりの余白

点の直径を 1 単位とする。マークの外形から、四方に 1 単位を空ける。

## してはいけないこと

| してはいけない | 理由 |
| --- | --- |
| グラデーション、影、ぼかしを付ける | 均一の平らな色だけ |
| 回転する | 点が右上にあることが形の意味 |
| 縦横を伸ばす、縮める | 線の太さが変わる |
| 決めた色以外にする | 色の展開の表のものだけ |
| 枠や丸で囲む | アプリのアイコンの角丸の面だけ例外 |
| 線と点をつなぐ、点を近づける | 点は線から離す |

## 作りの注意

| 項目 | 中身 |
| --- | --- |
| マークの path | stroke ではなく塗りの path。3 本のベジェ曲線の芯線から、一定の太さの外形を計算して作った。端の丸は円弧 |
| 太さ | 通常は viewBox の 100 に対して線 15 ほど、点の直径 17 ほど |
| 字 | `logo-horizontal.svg` の「KNOW IDEA」は path に輪郭化した。IBM Plex Sans 700(OFL-1.1、`@fontsource/ibm-plex-sans`)から opentype.js で作る(`node outline-logo.mjs`)。字間は元の `letter-spacing` 3.2 に合わせ、カーニングも入れた。書体の無い環境でも同じ形で出る。前後の比較は `samples/shots/logo-light.png`、`logo-dark.png`(上が前、下が後。字の右端のずれは約 1 単位) |
| 色の切り替え | `logo-horizontal.svg` と `favicon.svg` は `prefers-color-scheme` で色が変わる |
